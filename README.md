# Lupa

Prototyp einer Sammel-App für die 116 Säugetierarten Deutschlands (Rote Liste, BfN 2020).

- Sichtungen mit Datum, Ort (GPS oder aus Fotodaten) und eigenen Fotos
- Fortschritt, Ordnungen, Abzeichen
- Alle Daten bleiben lokal im Browser des jeweiligen Geräts

Artfotos: Wikimedia Commons, Urheber und Lizenzen in der App unter „Bildnachweise“.
